### Featured projects

**[Element Atlas](https://github.com/dilipxp/element-atlas)** · React 19 · TypeScript (strict) · Three.js  
Interactive 3D periodic table of all 118 elements. An imperative Three.js engine (instanced rendering, single-texture label atlas) sits behind a thin React bridge, with search, filters, trend visualizations, comparisons, quizzes and guided tours. Includes a 2D fallback when WebGL is unavailable, keyboard navigation, reduced-motion support, and a Python script that verifies every chemical equation in the dataset balances.

**[Hideaway](https://github.com/dilipxp/hideaway-vscode)** · TypeScript · VS Code Extension API  
A one-keystroke screensaver for VS Code that restores your exact session afterwards: editor groups, cursors, selections, scroll positions and focus. Works within the limits of the extension API using a webview tab, runs under a strict nonce-only Content Security Policy, and validates user-supplied images by file type and size.

**[PixiJS Tutorials](https://github.com/dilipxp/pixijs-tutorials)** · TypeScript · PixiJS  
Documentation and runnable examples covering PixiJS fundamentals: rendering, sprites, animation, interactivity, particles, filters, scene management and a mini slot-game example.
